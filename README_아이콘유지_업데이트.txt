WORKTIME v4.1 - GitHub Pages 아이콘 유지 버전

필수 업로드 파일
- index.html
- manifest.json
- icon-192.png
- icon-512.png
- apple-touch-icon.png
- favicon-32.png
- favicon-16.png
- .nojekyll

중요
1. 위 파일들을 GitHub Pages가 실제 배포하는 폴더의 최상위에 업로드합니다.
2. 기존 index.html은 새 index.html로 교체합니다.
3. manifest.json과 아이콘 파일도 함께 업로드합니다.
4. 파일 이름은 변경하지 마세요. 같은 경로를 계속 사용해야 홈 화면 아이콘이 안정적으로 유지됩니다.
5. GitHub Pages 주소(도메인/저장소 경로)를 유지하세요.
6. 업데이트 후 휴대폰에서는 기존 홈 화면 아이콘을 한 번 삭제하고 최신 웹주소에서 '홈 화면에 추가'를 다시 하는 것을 권장합니다.
7. 이후에는 같은 웹주소와 같은 아이콘 파일을 유지하면서 index.html만 업데이트하면 됩니다.
8. 브라우저의 사이트 데이터/캐시를 강제로 삭제하면 아이콘 또는 저장 데이터가 영향을 받을 수 있습니다.

Android Chrome
- 웹주소 접속 → ⋮ → 홈 화면에 추가
- 아이콘으로 WORKTIME이 표시됩니다.

iPhone Safari
- 웹주소 접속 → 공유 → 홈 화면에 추가
- apple-touch-icon.png가 홈 화면 아이콘으로 사용됩니다.

데이터
- 기존 사용자/출퇴근 데이터는 코드에서 삭제하지 않습니다.
- 사용자 001~006 정보와 기록 저장 로직은 유지됩니다.
